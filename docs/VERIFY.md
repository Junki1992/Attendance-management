# 動作確認手順

## 1. 起動

```bash
npm run dev
```

ブラウザで **http://localhost:3000** を開く（自動で `/login` に飛びます）。

---

## 2. ログイン

- **Firebase 設定済み**（`.env.local` に `NEXT_PUBLIC_FIREBASE_PROJECT_ID` などあり）  
  - 画面上部：**メールアドレス**と**パスワード**を入力し「ログイン」  
  - Firestore の `users/{uid}` に `name`, `role`（`admin` or `staff`）, `email` があるアカウントのみ入れる  
  - 下の「開発・検証用」を開くと、パスワードなしのモック（管理者 / スタッフ）も利用可
- **Firebase 未設定**  
  - 開発用モックの 2 ボタンのみ（管理者 / スタッフ）

**Firebase Auth の準備（メール+パスワードを使う場合）**

1. Firebase コンソール → Authentication → ログイン方法で「メール/パスワード」を有効化  
2. テスト用ユーザーを追加（または ユーザー タブで手動作成）  
3. Firestore の `users` に、Auth の **UID をドキュメント ID** にして `{ name, role: "admin" or "staff", email, hourlyWage }` を保存

---

## 3. スタッフ側の確認

| 確認項目 | 場所 | 期待する動き |
|----------|------|--------------|
| メニュー | ヘッダー | 「ホーム」「シフト提出」「確定シフト」「チャット」「ログアウト」が日本語で出る |
| ホーム | `/staff` | カード 3 つ：シフト提出、確定シフトを見る、チャット |
| シフト提出 | `/staff/shifts` | 月間カレンダー、日付クリックで 9–18 / 10–19 / OFF 切り替え、「提出内容を保存」 |
| 確定シフト | `/staff/confirmed-shifts` | 月切り替え（‹ ›）、確定済みだけ表示。勤務合計・概算給与。「変更申請」で確定後シフトの変更を申請できる。申請状況が一覧表示される |
| チャット | `/staff/chat` | 総務とのチャット。メッセージ送受信（Firestore `messages` が必要） |
| 通知 | ヘッダーの 🔔 | 未読があればバッジ。クリックで一覧（Firestore `notifications`） |

※ Firestore に `users`（`role: staff`）や `shifts` がなくても、モック／空表示でエラーにならなければ OK。

## 5. CSV コピーの確認

1. 管理者で `/admin/shifts` を開く
2. **CSVコピー** をクリック
3. スプレッドシート or メモ帳に **貼り付け（Cmd+V / Ctrl+V）**
4. 1 行目: `スタッフ,1,2,...,31,合計`
5. 2 行目以降: 名前, 各日の時間 or OFF or 空, 合計

※ 確定シフトが 1 件もない月は、名前と 0 だけの行になります。

---

## 6. エラーになる場合

- **Firebase 系**：`.env.local` に  
  `NEXT_PUBLIC_FIREBASE_*` が正しく入っているか確認
- **真っ白／真っ赤**：開発者ツールの Console にエラーが出ていないか確認
- **「users」などの Firestore エラー**：  
  プロジェクトに `users`, `shifts`, `messages`, `notifications`, `settings`, `shiftChangeRequests` コレクションを作成し、必要ならルールを設定
- **Firestore インデックス**：変更申請や通知の一覧で「インデックスが必要」と出たら、エラーメッセージ内のリンクから Firebase コンソールで作成
  - `shiftChangeRequests`: `(userId, createdAt)`, `(status, createdAt)`
  - `notifications`: `(type, createdAt)`
