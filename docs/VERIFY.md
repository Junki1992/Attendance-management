# 動作確認手順

## 1. 起動

```bash
npm run dev
```

ブラウザで **http://localhost:3000** を開く（自動で `/login` に飛びます）。

---

## 2. ログイン

- **管理者としてログイン** → `/admin` へ
- **スタッフとしてログイン** → `/staff` へ

---

## 3. スタッフ側の確認

| 確認項目 | 場所 | 期待する動き |
|----------|------|--------------|
| メニュー | ヘッダー | 「ホーム」「シフト提出」「確定シフト」「チャット」「ログアウト」が日本語で出る |
| ホーム | `/staff` | カード 3 つ：シフト提出、確定シフトを見る、チャット |
| シフト提出 | `/staff/shifts` | 月間カレンダー、日付クリックで 9–18 / 10–19 / OFF 切り替え、「提出内容を保存」 |
| 確定シフト | `/staff/confirmed-shifts` | 月切り替え（‹ ›）、確定済みだけ表示。勤務合計・概算給与。Firestore にデータがなければ「この月の確定シフトはまだありません」 |
| チャット | `/staff/chat` | 店長とのチャット。メッセージ送受信（Firestore `messages` が必要） |
| 通知 | ヘッダーの 🔔 | 未読があればバッジ。クリックで一覧（Firestore `notifications`） |

※ Firestore に `users`（`role: staff`）や `shifts` がなくても、モック／空表示でエラーにならなければ OK。

---

## 4. 管理者側の確認

| 確認項目 | 場所 | 期待する動き |
|----------|------|--------------|
| メニュー | ヘッダー | 「ホーム」「シフト表」「チャット」「ログアウト」が日本語 |
| ホーム | `/admin` | カード：シフト表、36協定アラート、チャット |
| シフト表 | `/admin/shifts` | ・‹ › で月切り替え<br>・**未提出者**がいる月：黄色カード＋「催促通知を送る」<br>・**CSVコピー**：クリックでクリップボードにコピー、「コピーしました」表示<br>・**確定して通知**：確認ダイアログ→確定＋スタッフへ通知<br>・表：スタッフ×日付、8h超は赤、週40h超は ⚠️ |
| チャット | `/admin/chat` | 左：スタッフ一覧（`users`  or モック）、右：チャット枠。スタッフ選択で会話 |

---

## 5. CSV コピーの確認

1. 管理者で `/admin/shifts` を開く
2. **CSVコピー** をクリック
3. スプレッドシート or メモ帳に **貼り付け（Cmd+V / Ctrl+V）**
4. 1 行目: `スタッフ,1,2,...,31,合計`
5. 2 行目以降: 名前, 各日の時間 or OFF or 空, 合計

※ 確定シフトが 1 件もない月は、名前と 0 だけの行になります。

---

## 6. エラーになる場合

- **Firebase 系**：`.env.local` に  
  `NEXT_PUBLIC_FIREBASE_*` が正しく入っているか確認
- **真っ白／真っ赤**：開発者ツールの Console にエラーが出ていないか確認
- **「users」などの Firestore エラー**：  
  プロジェクトに `users`, `shifts`, `messages`, `notifications` コレクションを作成し、必要ならルールを設定

---

## 7. ビルド確認

```bash
npm run build
```

`✓ Compiled successfully` で完了すれば、本番ビルドも問題ありません。
