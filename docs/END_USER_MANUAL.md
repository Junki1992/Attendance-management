# ユーザーマニュアル（エンドユーザー向け）

対象: 本アプリを操作するエンドユーザー（スタッフ／管理者）

---

## 概要
勤怠管理アプリの基本的な使い方をまとめたマニュアルです。ここでは日常的に使う操作（ログイン、プロフィール、チャット、通知）の操作手順とトラブル時の対処法を分かりやすく説明します。

## ログイン
- アプリを利用するにはログインが必要です。ログインしたアカウントでできる操作が変わります。

## プロフィール
- プロフィール画面で表示名やプロフィール写真を設定・編集できます。
- プロフィール写真は自分のアカウントのみ変更できます。変更後、画面上の写真が更新されます。

## 役割（admin / staff）
- 管理者（admin）とスタッフ（staff）の2種類の役割があります。管理者は一部の管理機能にアクセスできますが、日常利用者は通常のチャット・プロフィール編集で問題ありません。

## チャットの使い方（基本）
1. チャット画面を開くと、相手とのメッセージ履歴が表示されます。
2. テキストを入力して「送信」ボタンを押すとメッセージが送信されます。空白のみのメッセージは送信できません。
3. ファイル添付:
   - クリップ（添付）ボタンを押してファイルを選択します。
   - サポートされる形式は画像（jpg/png 等）と PDF のみです。
   - 画像はチャット内でプレビュー表示され、PDF はダウンロードリンクとして表示されます。
4. 既読表示:
   - 自分が送信したメッセージは、相手がそのメッセージを確認した場合に「既読」と表示されます（反映に数秒の遅延が生じることがあります）。

## 画面ごとの使い方（短縮マップ）
- ログイン: `/login` → メール/パスワードでログインします。  
- 新規登録: `/signup` → アカウント作成（名前・メール・パスワード）。  
- スタッフ：シフト提出: `/staff/shifts` → カレンダーで希望日を選択し「提出内容を保存」。  
- スタッフ：確定シフト確認／申請: `/staff/confirmed-shifts` → 管理者が確定したシフト確認・変更申請。  
- スタッフ：チャット: `/staff/chat` → 管理者グループとのやり取り。  
- 管理者：シフト表（一覧・確定）: `/admin/shifts` → 全スタッフのシフト確認、確定・通知。  
- 管理者：変更申請管理: `/admin/shift-change-requests` → スタッフの申請を承認/却下。  
- 管理者：チャット: `/admin/chat` → スタッフと個別チャット。  
- 管理者：設定／ユーザー管理: `/admin/settings` → 締切日、ユーザーの役割変更など。

## トラブルシューティング（具体例）
- ファイルアップロード中に「失敗しました」と出る  
  - 対処: ファイル形式を確認（画像/PDF）。ファイルサイズが大きい場合は圧縮して再送。ブラウザのコンソールにエラーがある場合はスクリーンショットを添えて管理者へ報告してください。  
- シフト提出で「保存に失敗しました」と出る  
  - 対処: シフト提出の締切日を確認してください（管理者が設定）。締切内であればネットワーク接続を確認し、再試行。改善しない場合はスクリーンショットと発生手順を管理者に報告してください。  
- チャットで「権限エラー」が表示される  
  - 対処: 一時的な表示不具合の可能性があるため、ログアウト→再ログインを試してください。解決しない場合はスクリーンショットとアカウント情報（メール）を管理者へ送ってください。  

## クイックスタート（すぐやる）
1. ログイン（/login）  
2. スタッフの場合: /staff/shifts で希望シフトを入力 → 「提出内容を保存」  
3. チャットで管理者へ連絡（/staff/chat）または管理者は /admin/chat でスタッフとやり取り

## 複数相手のチャット（スタッフ向け）
- スタッフ用ビューでは、複数の相手（例：管理者グループ）から届いたメッセージを1つのリストで確認できます。操作は通常のチャットと同様です。

## 通知
- 新しいメッセージが届くとアプリ内通知が表示されます。通知一覧から個別のメッセージに移動できます。

## モバイルでの使い方
- 画面幅が狭い場合、入力欄が画面の下部に固定されて表示され、片手で操作しやすくなっています。
- 入力時の表示崩れがあれば画面をリロードしてみてください。

## よくあるトラブルと対処法
- ファイルが送れない:
  - 対応形式（画像／PDF）以外は送れません。別形式の場合は変換してから再試行してください。
  - ファイルサイズが大きい場合は分割や圧縮を検討してください。
- メッセージが表示されない:
  - インターネット接続を確認し、ページを再読み込みしてください。
  - ログアウトして再ログインすると解決する場合があります。
- 既読表示が遅い:
  - 既読の反映に数秒から数十秒の遅延が発生することがあります。しばらく待ってから確認してください。

## 利用上の注意（簡潔）
- 添付できるファイル形式は画像とPDFに限定されています。
- 長文や重要な連絡はチャットの履歴を保存しておくことをおすすめします。

## サポートへの連絡
- アプリ内の管理者連絡先、または職場のシステム管理者へお問い合わせください。操作方法や表示の不具合についてはスクリーンショットを添えて報告すると対応が早くなります。
